# Getting Started with Tesseract

**Quick Answer:** Tesseract enables trustless cross-rollup atomic swaps across Ethereum L2s. 
Connect to the dashboard, select your source and target chains, create a swap order, and the 
protocol handles atomic execution with MEV protection.

## Key Facts

- Supported networks: Ethereum, Polygon, Arbitrum, Optimism, Base
- Protocol fee: 0.2% (50% discount for TESS stakers)
- MEV protection: Commit-reveal pattern
- Flash loan resistance: 2-block minimum delay

## Prerequisites

Before starting, you need:

1. **Wallet**: MetaMask or any Web3 wallet
2. **Tokens**: Tokens on a supported network
3. **Gas**: Native tokens (ETH/MATIC) for transaction fees

## Step 1: Connect Your Wallet

1. Navigate to the [Tesseract Dashboard](/dashboard)
2. Click "Connect Wallet"
3. Select your wallet provider
4. Approve the connection

## Step 2: Select Networks

1. Choose your **Source Chain** (where your tokens are)
2. Choose your **Target Chain** (where you want tokens)
3. Select the token pair to swap

## Step 3: Create Swap Order

1. Enter the amount to swap
2. Set your minimum receive amount (slippage protection)
3. Review the transaction details
4. Click "Create Order"

## Step 4: Commit Phase

Your swap order is submitted as a cryptographic commitment:

- Transaction details are hidden from MEV bots
- Only the hash is visible on-chain
- Wait for commitment confirmation (1-2 blocks)

## Step 5: Reveal Phase

After commitment confirmation:

- Reveal window opens (12-100 blocks)
- Your wallet prompts you to reveal
- Sign the reveal transaction
- Protocol verifies your payload matches commitment

## Step 6: Resolution

The relayer network handles execution:

- 2-block delay for flash loan protection
- Dependencies resolved automatically
- Atomic execution on target chain
- Tokens transferred directly to your wallet

## Transaction States

| State | Description |
|-------|-------------|
| BUFFERED | Order submitted, awaiting reveal |
| READY | Dependencies resolved, ready for execution |
| EXECUTED | Swap completed successfully |
| FAILED | Swap failed, eligible for refund |
| REFUNDED | Funds returned to sender |

## Troubleshooting

### My reveal timed out

If you miss the reveal window, your transaction expires automatically. 
You can claim a refund from the dashboard.

### My swap failed

Check the transaction on the block explorer. Failed swaps are eligible 
for automatic refund after expiration.

### How long does a swap take?

Typically 2-5 minutes depending on:
- Source chain block time
- Target chain finality requirements
- Current network congestion

## FAQ

### What is the minimum swap amount?

There's no protocol minimum, but small swaps may not be economical 
due to gas costs.

### Can I cancel a swap?

Before reveal: Yes, let it expire and claim refund.
After reveal: No, the swap will execute or fail atomically.

### How do I get TESS for fee discounts?

TESS tokens can be acquired through supported exchanges. 
Stake 10,000+ TESS for a 50% fee discount.
